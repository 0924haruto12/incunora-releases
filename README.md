# INCUNORA — Desktop releases

物語型放置RPG『INCUNORA』のWindows向けポータブルビルドの配布場所です。

- 公式サイト: https://incunora.com/
- ブラウザ版(無料): https://play.incunora.com/

## 使い方

1. [Releases](https://github.com/0924haruto12/incunora-releases/releases/latest) からZIPをダウンロード
2. 任意のフォルダへ展開
3. `INCUNORA.exe` を実行(インストール作業はありません)

- 対応: Windows 10/11(64ビット)
- セーブ: `%APPDATA%\Chronicle` に自動保存
- 未署名ビルドのため、初回起動時にSmartScreenの警告が表示される場合があります(「詳細情報」→「実行」)
